# Product and MVP

## Target User
Analyst who needs to discover relevant satellite locations without knowing every location in advance.

## Primary User Flow

```text
Natural-language query
        ↓
Optional AOI/date/sensor filters
        ↓
Semantic retrieval
        ↓
Ranked results
        ↓
Select location
        ↓
Before/after temporal evidence
        ↓
Change assessment
        ↓
Analyst confirm/reject
        ↓
Provenance-preserving result
```

## MVP Acceptance Criteria
- [ ] Search by natural language
- [ ] Search by image
- [ ] Filter by AOI/date/sensor
- [ ] Rank results
- [ ] Compare temporal imagery
- [ ] Suppress obvious false alarms
- [ ] Show confidence
- [ ] Show provenance
- [ ] Run offline
